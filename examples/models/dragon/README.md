# Stanford Dragon

This repository-bundled glTF contains the Stanford Dragon scan from the Stanford University
Computer Graphics Laboratory. The source scan is provided under the
[Stanford 3D Scanning Repository](https://graphics.stanford.edu/data/3Dscanrep/) terms.

The existing glTF conversion was generated with `qtek fbx2gltf` and has been part of Hilo3D since
the repository's initial import.
