# Khronos Car Concept

`CarConcept.glb` is an unmodified binary asset from
[KhronosGroup/glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept).
It demonstrates `KHR_materials_clearcoat`, `KHR_materials_emissive_strength`,
`KHR_materials_iridescence`, `KHR_materials_transmission`, `KHR_materials_variants`, and
`KHR_texture_transform`.
