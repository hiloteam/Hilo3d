# Audio validation — 2026-10-04

Scope: Unreleased `@hilo/addon-audio` working-tree implementation on base commit `a87175f9`.
Environment: macOS, Node 25.8.1, npm 10.9.4, Playwright Chromium. This is local functional evidence,
not a release, a physical-device latency measurement or an enrolled RHI benchmark.

## Passed checks

- `npm run test:audio`: 5 files, 33 tests. Real OfflineAudioContext PCM covers scheduling,
  interrupted/future fades, stereo direction, listener orientation, attenuation, cones, Doppler,
  occlusion recovery, convolution and ducking. Transport, concurrency, rollback, cache cancellation,
  pinning, teardown and Stage camera replacement also pass.
- Bounded allocation contract: 128 logical voices and 4 real slots, with 1,000 steady updates and no
  additional gain/source node creation. This does not measure end-to-end latency or compare
  performance with Unity/Unreal.
- `npm run lint`, `npm run typecheck`, `npm run test:types` and `npm run format:check`.
- `npm run api:update` followed by `npm run api:check`; the new report is maintained source.
- `npm run test:package`: actual installed tarballs pass Node ESM imports, source-map checks, recipe
  compilation/bundling, native audio decoding, genuine-click unlock, streaming play/pause/ seek,
  rendered PCM and owned-context teardown. Existing Live2D and asset package checks also pass.
- `npm run test:addon-audio-package`: publint, ESM-only export/type checks and pack whitelist.
- `npm run docs:check`, `npm run check:modernity` and `npm run release:versions:check`.

## Evidence limits

The full `npm run validate`/`npm run validate:ci`, complete renderer/RHI/shader/UI suites and
physical GPU lanes were not run. This change adds no renderer or shader implementation.
Firefox/WebKit, mobile interruption/background policies, hardware audio latency, perceptual
listening and sustained device memory/CPU profiles remain unverified. Autoplay/codec/device behavior
remains browser-specific. No npm publication was performed. See the [audio contract](../AUDIO.md)
and [remaining work](../ROADMAP.md#audio-extensions).
