核对日期：2026-10-29。范围：99 个 HTML 入口，其中 97 个场景示例、两个画廊入口。

## 整理结果

- 目录改为逐项审阅的元数据，删除文件名正则分类、自动拼标题和通用套话。新增页面仍由递归 HTML 扫描发现，缺少说明会直接报错。
- 精选由原 46 项整理为 24 项，加入 Atelier 昼夜 DDGI 室内场景、NOCTURNE 交互钢琴、雨后茶寮和 Soft
  Matter 材质展厅与 STRATA 风蚀石庭后现为 29 项；其余示例继续通过全部目录、主题筛选或搜索访问。诊断与验收场景集中到 Diagnostics
  & internals。
- 将计算渲染、后处理与离屏渲染分开；纠正深度纹理、法线贴图、相机辅助线、GTAO 验收等错分项。
- 删除四个没有独立 API 教学价值的页面：Canvas 动画并入 Canvas 仪表盘，独立 UBO 页面并入自定义 Shader，最小 PBR 加载并入 glTF
  Loader，后端名称显示由共享 Stats 承担。当前保留 97 个场景；按实际能力和回归覆盖评估增删，不为旧 URL 保留重复页面。
- 删除未被入口、脚本或测试引用的 `NormalTangentHelper.ts` 和
  `postalUi.ts`；保留仍被场景引用的模型、纹理及来源说明。
- 去掉旧页面禁止用户缩放的 viewport 参数，明确基础页面标题。动态缓冲示例改由场景更新推进，删除独立的定时器。
- 静态构建删除 Blender 创作源文件的复制路径，运行时资产保留；仓库中的原始创作文件与授权说明保留。
- 画廊提供多词搜索、中文主题关键词、主题/后端筛选、URL 状态、浏览器前进后退、手机键盘导航和加载失败重试。主题数量和筛选结果遵循当前 Highlights

新增 Audio 主题及精选
[NOCTURNE — 魔法钢琴](../examples/audio_piano.html)，在黑暗空间里弹奏石墨色钢琴，每个琴键分别生长青蓝星尘与流动光羽，展示程序化着色器、空间声源和立体声卷积混响，也支持导入仅在页面内存中处理的本地 MIDI 曲谱。冷色轮廓光勾勒琴体；细尘、稀疏亮点和卷曲薄雾随音符生长并消散，演奏时显出极淡的程序化星云。默认演奏用户提供并确认可使用的
[Call of Silence 钢琴 PDF](../examples/audio/call-of-silence.pdf)
转录曲谱，保留双手声部、69 小节与延音线，采用 84
BPM。美术灵感来自何同学的魔法钢琴：静默时保持黑暗，演奏时由音符各自点亮琴键上方，按住继续发光，松键后渐暗；舞台没有地面光圈。声音经用户手势启动，渲染支持 WebGL
2 与 WebGPU。

[雨后茶寮 / After the rain](../examples/rain_tea_garden.html) 将 Blender
MCP 创作的清新日漫庭院与动态 GI、共享阴影体积光、落花贴花和加权透明组合在同一场景，提供晨光与薄暮两种光照。归入 Lighting
& shadows，明确要求 WebGPU。概念图、资产路径、交互与验证边界见[案例说明](./RAIN_TEA_GARDEN.md)。

[STRATA / 风蚀石庭](../examples/meshlet_strata.html)
将 Blender 创作的暖色砂岩环庭与分层浮雕用于展示 meshlet 几何和真实分页流送。Overview、Passage、Surface 三个镜头从远景轮廓推进到近处表面，Adaptive
/ Coarse 与流送开关允许观察页面请求和 CPU/GPU 计数变化。归入 Render targets &
passes，作为 WebGPU-only 精选；格式和功能边界见[meshlet 几何合同](./MESHLET_GEOMETRY.md)。

## 运行时维护

- 通用页面使用 `createExampleContext`；需要自行配置灯光、后处理和诊断的页面可使用
  `createExampleStage`。创建前建立页面所有权，初始化取消时释放迟到的 Stage。
- `pagehide.persisted` 暂停调度并保留资源，`pageshow.persisted`
  恢复原有启动/暂停意图；最终退出先停止ticker，再执行 `onDispose`
  场景清理，最后释放 Stage。模型、动画、离屏目标、事件监听和媒体源由所属页面登记清理。
- 异步模型替换、纹理加载和 GPU
  readback 在发布结果前检查所属页面或请求代次；最终销毁后的回调不能重新启动渲染。后处理 kernel 对比串行执行，视频解码、网格创建和自动播放授权分别处理。
- Canvas 仪表盘最多每秒重绘/标记上传 30 次；场景仍独立渲染。重复材质、粒子/物理临时数组复用，路径标记只在路径变化时更新；诊断读数和 DOM按需更新，保留真实渲染及交互测试。
- 自定义图像 shader 使用 `hiloTextureUV`；屏幕预览由内置 `screen.vert`
  完成一次 render-target 转换。新增合同覆盖源代码边界和真实 Naga 翻译，双后端编译、管线创建和方向性像素检查仍由浏览器矩阵负责。

本轮 Node 合同、类型和构建检查与浏览器证据分别记录。当前运行环境拒绝本地浏览器服务监听（`listen EPERM`），因此不据此批准视觉基线或声称帧率提升。
